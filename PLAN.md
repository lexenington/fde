# The 16-week plan

About **12 hours a week**. If you only have 8, stretch it to 20-24 weeks, not by skipping the engagements. Progress is tracked in [PROGRESS.md](PROGRESS.md); this file says what to do *this week*. The Console's **This week** page (http://localhost:3300/plan) shows the current week and your progress.

## The weekly rhythm

| When | What | Time |
|---|---|---|
| **Monday** | Read the week's page(s). Write `SCOPE.md` (or update it) *before* any code. 20 minutes on the tool of the week | 1 h |
| **Tue, Wed, Thu** | Build sessions, 90 minutes each. One capability per session, then run the checker | 4.5 h |
| **Friday** | Run the checker, **draw an inject card** if the lab has them, write the weekly update ([template](03-customer-craft/templates/weekly-update.md)), tick `PROGRESS.md`, commit | 1.5 h |
| **Weekend** | One long block (3 h): the hardest item of the week, a stakeholder call, or outreach | 3 h |
| **Every week** | One **stakeholder call** in the Console and one **outreach message** to a real business (see below) | in the blocks above |

**Rules that keep it honest**

- Commit at the end of every session. The git history, with the committed checker runs, is your evidence.
- Read the *first* failing hint only. Fix it, then run again.
- If you are more than a week behind, drop **stretch** items first, then the module you can already do (each has a "Prove it" check), never an engagement.
- Every lab ends with a one-page report written for its audience, then cut by 30%.

## When life happens

| Situation | Do this |
|---|---|
| Missed a week | Don't double up. Cut stretch items, keep the engagements |
| A lab is stuck | Time-box to two sessions, then book a stakeholder call or ask Claude to review (not solve) your code with `practice-with-claude.md` prompt 4 |
| No real customer replied | Send 5 more messages this week; widen to friends-of-friends. Fall back to a simulated third engagement only after week 8, and say so in the case study |
| You already know a module | Do its "Prove it" check cold. If it passes, skip it and use the time on an engagement |
