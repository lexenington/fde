# Resources

Curated, not exhaustive. If you only do the starred ones, you're fine.

## The role
- ★ Search "forward deployed engineer" on the engineering blogs of Palantir, OpenAI and Anthropic, and on Lenny's Newsletter / a16z. Read 3 recent first-person accounts of the job
- Current job postings themselves: the most accurate description of what's wanted *right now*

## AI engineering
- ★ Anthropic, "Building effective agents" (anthropic.com/engineering)
- ★ Anthropic docs: prompt engineering, tool use, structured outputs, prompt caching, evals ("Define success criteria" / "Develop tests") at platform.claude.com/docs
- ★ Hamel Husain's writing on LLM evals (hamel.dev): the most practical material on error analysis
- Chip Huyen, *AI Engineering* (O'Reilly, 2025)
- Simon Willison's blog on prompt injection (simonwillison.net)
- OWASP Top 10 for LLM Applications
- ★ modelcontextprotocol.io: spec, quickstarts for building servers, and the authorization section
- Claude Agent SDK docs (code.claude.com/docs/en/agent-sdk) and Managed Agents docs, to know when each fits
- Masakhane (masakhane.io) and Ghana NLP: research and datasets for African languages, useful for building Twi/Ewe/Ga eval slices

## Data
- ★ dbt docs: "How we structure our dbt projects"
- Peter Christen, *Data Matching*: entity resolution
- Martin Kleppmann, *Designing Data-Intensive Applications*: chapters 3, 5, 11

## Integration & security

- Stripe's engineering posts on idempotency keys
- Ghana Data Protection Act 2012 (Act 843) + Data Protection Commission guidance
